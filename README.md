# SafeCert

건축·소방 평면도를 분석해 현행 법령 기준의 안전상태를 도면 위 색으로 표시하고, 근거와 설명을 함께 보여주는 소프트웨어.

## 현재 단계 — 사전 파일럿 (MVP 전)

| 항목 | 내용 |
|---|---|
| 형태 | **iPad 전용 네이티브 앱** — SwiftUI · SwiftData · Apple 퍼스트파티 프레임워크만(외부 라이브러리 0, 서버 없음). 생성형 AI 만 외부 LLM(Google Gemini API) 호출 |
| 대상 | 다중이용업소 영업장 평면도 · CAD 에서 출력한 **벡터 PDF**(글자를 외곽선으로 출력한 도면은 기기 내 글자 인식 Vision 으로 읽음) |
| 규칙 | 비상구 설치(시행령 별표 1의2 제2호·고시) · 비상구 위치 이격(시행규칙 별표 2 제2호가목1) · 비상구등 규격(같은 목 2) |
| 법령 | 매일 05:00 KST 국가법령정보 공동활용 API 실측 → 조문 정규화(독립 코드 파서 2종) → 코드 검증 5종 → 법령 스냅샷. 앱 실행·판정 직전에 당일 스냅샷이 없으면 즉시 실측 |
| 판정 | 결정적 규칙 엔진. LLM 불관여. 판단 불가 항목은 초록 금지 |
| 설명 | 판정 상세 7단 + 조문 원문(그날 스냅샷) 직접 삽입. 「쉬운 말 요약」은 외부 LLM 초안 · 사실 대조 실패 시 폐기 |
| 검토자 확인 | 판정마다 확인 체크(체크 시각 기록) — 도면 표식·결과 카드·보고서에 함께 표시. 확인 상태가 바뀌면 이전 보고서는 다시 만든다 |
| 보고서 | 판정 후 **사전검토 보고서 PDF** — 판정·색·값·조문 원문은 규칙 엔진 결과 그대로, 요약·판정 설명·확인 방향은 외부 생성형 LLM 이 쓰고 근거 대조를 통과한 문장만 「AI 작성」 표시로 싣는다(아래) |
| 표시 | 전 화면·보고서 「감수 전·참고용」 |

### 색과 법령 상태

| 색 | 의미 |
|---|---|
| 빨강 | 의무 미충족 |
| 주황 | 위반 가능성 · 확인 필요(경계값·표기 없음·예외 확인 등) |
| 노랑 | 기준 변경 감지 — 자동 검증 실패 또는 조문 문구(해석) 변경 시, 이전 기준으로 계산한 결과에 표시 |
| 초록 | 확인 범위 내 적합 |
| 회색 | 자료 부족 · 대상 외(축척 미확정 등) |

코드 검증 5종: ① 형식 ② 원문 근거(뽑은 숫자가 원문에 숫자 경계째 있고, 원문 글자로 다시 계산한 값과 같은가) ③ 이중 정규화 일치 ④ 변화 폭 ⑤ 회귀(샘플 도면 재판정 — 무관 규칙 불변 + 엄격화·완화 방향 일관).
통과 = 새 값 반영(30일 「최근 개정」 표시) · 실패 = 이전 값 유지 + 노랑 · 문구 변경 = 자동 반영 안 함 + 노랑(원래 문구로 돌아오면 복귀) · 전면 수집 실패 = 전날 스냅샷 + 기준일 경고 · 일부 수집 실패 = 해당 조문 이전 수집본 + 「일부 수집 실패」 표식, 1시간 간격 재시도.

### 사전검토 보고서 (AI)

판정(규칙 엔진) → 근거 묶음 → **조문 검색(RAG)** → **외부 생성형 LLM 서술(Gemini)** → **근거 대조** → PDF 조판 → 공유.

| 단계 | 내용 |
|---|---|
| 조문 색인 | 매일 수집한 법령 전문(법·시행령·시행규칙·고시)을 조·별표 행·고시 조 단위 구절로 나눠 스냅샷에 저장 |
| 조문 검색 | 판정마다 한글 두 글자 BM25 로 관련 구절을 찾는다(기기 안·결정적). 법령 전문(약 6만 자) 대신 관련 구절만 넣어 근거를 좁히고 입력을 줄인다 |
| 서술 | Gemini API `gemini-3.5-flash-lite`(무료 티어) 구조화 생성(JSON 스키마: 요약 3~4문장 · 판정 설명 2~3문장 · 확인 방향 1~3항목), 판정마다 따로 호출 · 온도 0 · 일시 오류 1회 재시도 |
| 보내는 것 | 판정 결과 글과 법령 조문만. 도면 파일·이미지·검토 이름은 보내지 않는다. 보낼 때마다 화면에서 확인(무료 티어는 입력이 제품 개선에 쓰일 수 있음) |
| 근거 대조 | 사실에 없는 숫자·판정 색, 색↔항목 짝 오류, 적합/부적합·벌금·단정 표현이 든 문장은 뺀다. 전부 빠지거나 모델을 못 쓰면 규칙 엔진 문장으로 채우고 모델 이름을 적지 않는다 |
| PDF | A4 · 표지(법령 기준일·검토 범위·전체 판정·고정 문구) · 도면 표시(원본 벡터 + 판정 번호) · 판정 절(7단·조문 원문·관련 조문) · 작성 정보(AI 문장 수·뺀 수). 쪽마다 「감수 전 · 참고용」 |

API 키는 앱 설정에 넣으면 키체인에 보관한다(코드·저장소에 없음). 키가 없거나 호출이 실패하면 보고서는 규칙 엔진 문장으로 나온다.

## 구조

| 경로 | 내용 |
|---|---|
| `packages/SafeCertKit` | 순수 로직 Swift 패키지(iOS·macOS 26, 외부 라이브러리 0) |
| ├ `Geometry` | 점·선분·다각형·원호 맞춤·평면 그래프 면 추출 |
| ├ `Drawing` | 벡터 PDF 해석(CGPDFScanner·PDFKit) · 외곽선 글자 인식(Vision, 0°·90°·270°) · 페이지 렌더러 |
| ├ `Plan` | 평면 해석(상대 굵기 벽 층·곡선/직선 조각 원호 문·외곽·실·출입구 역할·문 규격) · 축척 추정(표기 + 치수 교차검증, 축소·확대 인쇄 감지) |
| ├ `Law` | 법령 API · 응답 해석 · 조문 추출 · 정규화 · 코드 검증 · 스냅샷 |
| ├ `Rules` | 규칙 엔진 · 조건 · 판정 모델 · 회귀 세트 |
| ├ `Explain` | 판정 설명 7단 · 쉬운 말 초안 |
| ├ `Report` | 사전검토 보고서 — 조문 검색 · 근거 묶음 · 외부 LLM(Gemini) 서술 · 근거 대조 · PDF 조판 |
| ├ `Samples` | 시연용 샘플 도면 3종(CoreGraphics 생성, 일반형·CAD 출력형) |
| └ `Resources/LawSeed` | 법령 초기값(2026-10-12 API 응답 녹화). 첫 실행·오프라인 기준 |
| `apps/ipad` | iPad 앱(SwiftUI · SwiftData · PDFKit · BackgroundTasks · Security) |

## 빌드·시험

```sh
# 로직 시험 (macOS) — 84개(Gemini 실호출 1개는 GEMINI_API_KEY 가 있을 때만)
cd packages/SafeCertKit && swift test

# iPad 앱 빌드 (시뮬레이터)
cd apps/ipad && xcodebuild -project SafeCert.xcodeproj -scheme SafeCert \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)' build
```

요구: Xcode 27 · iPadOS 26 이상. 쉬운 말 요약·보고서 AI 서술은 설정에 Gemini API 키가 있을 때만 동작한다.

### 시연 실행 인자 (디버그 빌드 전용)

| 인자 | 동작 |
|---|---|
| `-SafeCertDemo sample-a\|sample-b\|sample-c` | 샘플 검토를 만들고(축척 확인) 판정까지 진행 |
| `-SafeCertDemoStep confirm` | 판정 전 확인 단계에서 멈춤 |
| `-SafeCertDemoStep report` | 판정 후 보고서 PDF 작성·미리보기까지 |
| `-SafeCertDemoConfirm N` | 앞 N개 판정에 검토자 확인 체크 |
| `-SafeCertDemoFloor yes\|no\|unknown` | 피난층 조건 |
| `-SafeCertDemoSelect N` | N번째 판정 상세를 펼침 |
| `-SafeCertDemoScreen law\|settings` | 법령 현황·설정 화면 |
| `-SafeCertDemoFile <이름.pdf>` | 앱 Documents 의 PDF 로 검토 생성(`xcrun simctl get_app_container … data` 의 Documents 에 복사). `-SafeCertDemoStep result` 판정까지, `-SafeCertDemoMultiUse no` 다중이용업소 아님 |

## 실도면 대응

실제 CAD 출력 PDF 의 흔한 특성을 처리한다(2026-10-13 실도면 1건으로 확인).

| 특성 | 처리 |
|---|---|
| 용지 맞춤 축소 인쇄(예: A3 1:150 → A4) | 치수 문자 다수가 가리키는 실제 출력 축척을 제시하고 표기와 다름을 경고 |
| 글자 = 외곽선 도형 | 기기 내 Vision 글자 인식(세 방향·타일), 결과는 검토에 저장 |
| 벽 = 칠한 단면, 얇은 펜 | 도면 안 상대 굵기로 벽 층 판별 |
| 문 궤적 = 직선 조각 | 짧은 직선 사슬 원 맞춤 |
| 창·문 틈으로 외곽이 열린 두 줄 벽 | 가장 넓은 벽 군집의 외곽 껍질(신뢰도 0.7 → 초록·빨강 없음) |

## 법령 API 인증값

`open.law.go.kr` 에서 신청한 인증값(OC)을 앱 설정에 넣으면 키체인에 보관한다. 없으면 공개 샘플 인증값(`test`)으로 호출하며 화면에 경고가 뜬다 — 운영 전 교체 필요.
