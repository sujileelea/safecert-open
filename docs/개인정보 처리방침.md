# SafeCert 개인정보 처리방침

시행일 2026-10-14 · 대상 앱 SafeCert (iPad, 테스트 버전 0.1.0)

## 1. 수집하는 개인정보

없음. 회원가입·로그인이 없고, 이름·연락처·위치·기기 식별 정보를 모으지 않습니다.

## 2. 기기 안에만 두는 것

| 항목 | 보관 위치 | 지우는 방법 |
|---|---|---|
| 올린 도면(PDF) · 검토 조건 · 판정 · 확인 체크 · 보고서 PDF | 이 iPad 안 | 검토 목록에서 삭제, 또는 앱 삭제 |
| 생성형 AI API 키 · 법령 API 인증값 | iPad 보안 저장소(키체인) | 설정 화면에서 삭제 |

## 3. 밖으로 보내는 것

| 받는 곳 | 보내는 것 | 언제 |
|---|---|---|
| 국가법령정보 공동활용 Open API | 법령 조회 요청(개인정보 없음) | 매일, 그리고 앱 실행·판정 직전 |
| Google Gemini API | 판정 결과 글(항목 · 색 · 읽은 값 · 기준)과 관련 법령 조문 | AI 문장을 만들 때, 화면에서 동의한 경우만 |

- 도면 파일 · 도면 이미지 · 검토 이름은 보내지 않습니다.
- Gemini 무료 등급은 보낸 내용이 Google 서비스 개선에 쓰일 수 있습니다(Google 이용약관). 원하지 않으면 「AI 없이 작성」을 고르면 됩니다.

## 4. 의견 보내기

앱 안 「의견 보내기」의 설문은 사용자가 고른 방법(메일 · 메시지 등)으로 직접 보냅니다. 앱은 의견을 저장하거나 서버로 보내지 않습니다.
