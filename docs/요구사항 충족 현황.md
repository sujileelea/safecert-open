# SafeCert — 과제 요구사항 충족 현황

기준일 2026-10-14 · ✅ 충족 · 🟡 일부 · ⬜ 예정

MVP = PDF 도면 올리기 → 현행 법령 기준 충족 여부를 도면 위에 색으로 표시 → 사람이 항목마다 확인(체크) → PDF 보고서 내보내기 (구현 완료)

## 핵심 요건

| 요구사항              | SafeCert 에서 하는 일                                                                                  | 상태  |
| ----------------- | ------------------------------------------------------------------------------------------------- | --- |
| 생성형 AI 가 핵심 기능    | 검토 보고서(PDF)의 요약·판정 설명·보완 방향 문장을 생성형 AI(Google Gemini)가 씀. 실제 호출 시험: 문장 20개 작성 · 검사에서 1개 제외 · 약 8초 | ✅   |
| 필수 기술 2개 이상       | RAG · 자동화 워크플로우                                                                                   | ✅   |
| └ RAG             | 매일 모은 법령 전문을 조문 단위로 나눠 두고, 판정마다 관련 조문을 찾아 AI 에 함께 전달                                              | ✅   |
| └ 자동화 워크플로우       | 매일 새벽 5시 법령 자동 수집 → 정리 → 자동 검증 → 판정 기준 갱신                                                         | ✅   |
| └ 멀티모달            | 도면 이미지 속 글자를 AI 로 읽어 판정에 사용                                                                       | 🟡  |
| 서비스 배포 | iPad 앱을 TestFlight(애플 공식 테스트 배포)로 배포. 버전 0.1.0 업로드 완료(내부 테스트) · 외부 테스터용 애플 베타 심사 예정 | 🟡 |
| 실사용자 5명 이상 피드백·반영 | 앱 안 「의견 보내기」(짧은 설문) 준비 완료 → 테스트 후 반영 | ⬜ |
| GitHub 버전 관리      | 공개 저장소 https://github.com/sujileelea/safecert-open — 기능 단위의 작은 기록 49건                             | ✅   |
